# 领域术语表

本文件是 power-system 领域术语的唯一来源，文档、代码命名与 AI 生成内容均以本表为准。

## 维护规则

1. 新增或调整领域概念时，在同一次改动中同步更新本表，并标注对应代码位置。
2. 代码中的类名、枚举值、字段名、包名应与“代码命名”列一致；文档与注释中的中文应与“术语”列一致。
3. 条目按业务域分组；跨业务共享的概念放入“核心共享”，单一业务概念放入对应业务域分组。
